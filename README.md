# Afrocentric Discovery Platform

An interactive network map and discovery tool connecting Afrocentric platforms, historical data, and location-based discovery filters.

## Tech Stack
- **Frontend:** React, Vite, Lucide Icons
- **Backend / Database:** Firebase (Firestore)
- **Data Pipeline:** Python (`main.py`, `run_pipeline.py`)
